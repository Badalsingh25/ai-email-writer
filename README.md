# ✨ Email Writer Assistant

**AI-powered email reply generator for Gmail — Spring Boot + React + Chrome Extension**

</div>

---

## What it does

Email Writer Assistant adds a **✨ AI Reply** button directly inside Gmail's reply toolbar. Pick a tone (Professional, Friendly, Casual, Formal), click the button, and a context-aware reply is generated by Gemini AI and inserted straight into your compose box.

The project has three parts:

| Folder | What it is |
|---|---|
| `email-writer-sb` | Spring Boot backend — REST API that talks to the Gemini API |
| `email-writer-react` | Standalone React web UI (paste an email, get a reply — no Gmail needed) |
| `email-writer-ext` | Chrome extension — injects the AI Reply button into Gmail |

---

## 🚀 Quick Install (just want to use the extension?)

You don't need to build anything from source. Grab the pre-built extension package from the **[Releases](../../releases)** page:

1. Download `email-writer-extension-vX.X.zip` from the latest release
2. Unzip it
3. Go to `chrome://extensions` in Chrome
4. Turn on **Developer mode** (top-right toggle)
5. Click **Load unpacked** and select the unzipped `email-writer-ext` folder
6. Open Gmail, click reply on any email — you'll see the **✨ AI Reply** button in the toolbar

> ⚠️ The extension talks to a Spring Boot backend running on `http://localhost:8080`. You'll need the backend running locally (see below) for the extension to actually generate replies — this project isn't hosted publicly.

## 🛠️ Running the full stack locally

### Backend (Spring Boot)

```bash
cd email-writer-sb

# Set your Gemini API key (get one free at https://aistudio.google.com/apikey)
export GEMINI_URL="https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key="
export GEMINI_KEY="your-gemini-api-key"

./mvnw spring-boot:run
```

Backend runs on `http://localhost:8080`.

### React web app (optional, no Gmail required)

```bash
cd email-writer-react
npm install
npm run dev
```

### Chrome extension (build from source instead of the release zip)

1. Go to `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** → select the `email-writer-ext` folder in this repo
